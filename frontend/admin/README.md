# Admin Panel

This folder represents the Admin Panel module for SimplDSC.

The admin components and layouts are mounted via React Router under `/admin` and `/admin/*`:
- Entry Layout: `src/pages/admin/AdminLayout.js`
- Login: `src/pages/admin/AdminLogin.js`
- Auth Context: `src/context/AdminAuthContext.js`
- Pages:
  - Dashboard: `src/pages/admin/AdminDashboard.js`
  - Orders: `src/pages/admin/AdminOrders.js`
  - Customers / Users: `src/pages/admin/AdminCustomers.js`
  - Documents: `src/pages/admin/AdminDocuments.js`
  - DSC & Expiry: `src/pages/admin/AdminDSCs.js`
  - Catalog / Products: `src/pages/admin/AdminCatalog.js`
  - Leads: `src/pages/admin/AdminLeads.js`
  - Agent Partners: `src/pages/admin/AdminPartners.js`
  - Payments & Reconciliation: `src/pages/admin/AdminPayments.js`
  - Support Tickets: `src/pages/admin/AdminSupport.js`
  - Notifications: `src/pages/admin/AdminNotifications.js`
  - System Settings: `src/pages/admin/AdminSystem.js`
